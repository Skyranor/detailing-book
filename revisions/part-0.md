# Ревизия части 0 (главы 1–7)

Проведена по промту [prompts.md §3](../system/prompts.md) после
написания глав 1–7. Формат: находка → что сделано. Находка без отметки
«применено» или «отклонено с обоснованием» считается открытой.

## Проверки, не давшие находок

| Проверка | Результат |
| --- | --- |
| Голые цифры без условий | Не найдено: все числовые значения даны диапазонами с условием либо помечены `[ПРОВЕРЬ TDS]` / ⚠️ ПРОВЕРИТЬ |
| Скрытая реклама, превосходные степени | Не найдено: бренды не названы ни разу во всей части, составы описаны классами |
| Обещания негарантируемого результата | Не найдено: раздел «Что нельзя обещать клиенту» есть в главах 1, 2, 3, 4, 5, 6, 7 |
| Пропущенная безопасность | Не найдено: раздел «Безопасность» есть во всех семи главах, включая обзорные |
| Подмена малярки детейлингом | Не найдено: граница проговорена в главах 1, 2, 3, 5 |
| «Как известно», «очевидно», «все знают» | Не найдено |
| Проходимость для сегмента A | После находок 1–4 — проходима |
| Полезность для сегмента F | Есть: разделы «Что меняется на потоке» и «Деньги» присутствуют в главах 1–7, хотя обязательны только с главы 8 |

## Три самые опасные ошибки части 0

Если читатель усвоит из части 0 только три вещи, это должны быть они.

1. **Толщиномер показывает сумму слоёв, а не лак.** Замер 120 мкм
   не означает запаса. Решение принимается по минимуму серии и по
   оценке доли лака ([глава 2](../chapters/02-paint-system.md),
   [глава 6](../chapters/06-measurement.md)).
2. **Работа приняли под тем светом, где брак не виден.** Голограммы
   не видны при рассеянном освещении и видны на солнце у клиента
   ([глава 5](../chapters/05-defect-optics.md)).
3. **Фторидный ожог не болит сразу.** Мастер, не знающий этого, теряет
   часы до обращения за помощью
   ([глава 7](../chapters/07-safety.md)).
